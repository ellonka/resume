Релевантный проект

Автоматизация генерации отчетности Python, FastAPI

Задача: Cформировать список кандидатов на награждение по заданным критериям в excel. Cгенерировать заполненные наградные листы по шаблону в формате docx. Данные взять из сформированного списка кандидатов.

Решение: Написала скрипт на Python для обработки критериев отбора и выборки кандидатов. С использованием openpyxl сформировала файл со списком кандидатов. Создала разметку шаблона наградных листов. С помощью docx сгенерировала заполненные наградные листы по списку кандидатов. Подняла локальный сервис на FastAPI для интреактивной работы с файлами.

Результат: Сократила время подготовки отчетности и выполнения рутинных операций с нескольких часов до минут, исключив ручной труд.
